# 四六级逐句精听

**把你手里的听力音频，做成一句一句可以单独练的网页。**

点句播放 · 先盲听再看原文 · 单句循环与减速 · 听写逐词对照 · 星标难句复习

![四六级听力，一句一句练](docs/assets/公众号封面-横版.png)

四级、六级英语听力都可作为输入。音频和可选的配套原文由你提供；制作后输出音频内嵌的单文件 HTML，在电脑浏览器打开就能练，也可离线使用。

## 新手先用 WorkBuddy

把下面这段话复制给 WorkBuddy，再提供你的音频即可。

> 请帮我安装这个四六级逐句精听 Skill：https://github.com/yb-beep/listening-sentence-index 。按仓库说明准备好环境；如果我还没提供音频，请提醒我提供。收到音频后，生成带英文原文和中文译文的单文件精听网页，抽查句首句尾，自动打开成品，并在桌面创建「四六级逐句精听」快捷方式，让我以后双击就能练。最后简单告诉我：怎么开始练，以及下次换音频时该发什么话。

有配套原文，也一起给智能体。下载、安装与环境准备由具备文件和脚本执行能力的智能体按仓库说明处理；首次需要依赖与模型。完成后智能体打开成品并创建桌面快捷方式，以后双击图标就能练。

本仓库提供可供智能体读取的说明与脚本。不是平台合作或官方推荐，也不表示所有客户端版本都已端到端测试。

## 制作后怎么练

1. 用电脑浏览器打开「单文件版」HTML。
2. 默认隐藏原文，点一句先听。
3. 没听懂就选「循环本句」或调慢速度。
4. 点「显示本句」核对，遮住再听；也可以切到听写。
5. 难句标星，下一轮「只看星标」集中复习。

## 自己运行脚本

准备 Python 3.10+，安装 `requirements.txt` 所列依赖。流水线使用 PyAV，不需要外部 ffmpeg 命令。

```bash
python scripts/prepare.py --install
python scripts/run_all.py --work ./out --audio ./listen.mp3 \
  --ref ./reference.txt --title "四六级听力精听"
```

没有原文时去掉 `--ref`。中文译文由智能体另行生成并写入 `translations.json`，随后重新生成页面；详见 [SKILL.md](SKILL.md)。

完整流水线顺序：转写 → 原文对齐 → 补漏 → 切分 → 索引 → 单文件 HTML。单文件版是主要交付物。中断后用 `--resume` 续跑已记录步骤；更改输入后重新处理相应输出。

## 运行与检查

首次安装、模型下载、翻译与抽听都会影响总耗时。自动识别、原文对齐和切分需要检查，不承诺固定分钟数或自动提分。页面上的听写比对依赖提供的英文原文。

当前版本 v0.1.1 修复音频格式、断点续跑、星标连播、学习记录隔离及导出等问题。[代码检查与修复说明](docs/代码检查与修复说明.md)包含具体触发条件与验证范围。

15 项 Python 回归测试与 12 项浏览器检查通过，并以 6 句自编合成语音跑通实际切分和网页生成。断点测试使用模型替身；没有将真实 Whisper 准确率、所有设备或全部智能体安装流程列为已验收。

安装依赖后可运行回归测试：

```bash
python -m unittest discover -s tests -v
```
