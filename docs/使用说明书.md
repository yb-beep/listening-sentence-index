# 四六级逐句精听使用说明

这套工具把长音频加工成逐句练习材料。制作和练习是两个阶段：制作需要能运行本地脚本的环境；拿到成品后，可以直接在电脑浏览器里练习。

## 拿到成品：先完成一次练习

1. 双击智能体为你创建的「四六级逐句精听」桌面快捷方式；也可以找到文件名含「单文件版」的 HTML，用电脑浏览器打开。
2. 保持「原文显示 → 全部隐藏」，点某一行的 ▶ 听一句。
3. 没听清，就再播一遍，或把「每句」改为「循环本句」。
4. 点「显示本句」对照原文。看完点锁形按钮，重新遮住再听。
5. 点 ☆ 标记难句。下一轮把「筛选」改为「只看星标」。

先从几句开始，不必第一次就设置所有功能。

## 常用功能速查

| 想做什么 | 页面里怎么操作 |
|---|---|
| 一句反复听 | 「每句 → 循环本句」；切句或停止时结束 |
| 留一点反应时间 | 「句间」选 1、2 或 3 秒 |
| 调语速 | 当前模板提供 0.6、0.75、0.9、1.0、1.2 倍速 |
| 只看当前句 | 点「显示本句」，或该句上的「显示原文」 |
| 再次盲听 | 点「全部重新遮住」或单句锁形按钮 |
| 连续练几句 | 设置起止序号，点「▶ 连播」 |
| 重复同一段 | 设置区间，点「↻ 循环区间」 |
| 两三句一起练 | 「每组」选 2、3 或 5 句；按需设置组重复次数 |
| 练一个板块 | 点击板块的播放按钮或「连播本板块」 |
| 找出漏词 | 「练习流程 → 听写」，输入英文后提交校对 |
| 集中复习难句 | 标星，再选择「只看星标」 |

「当前句作起点 / 作终点」设置的是**连播的句子范围**，不能修改音频切分时间。片段截断需要在制作阶段修正。

## 两种自动练习流程

**三阶段模式**：在连播时，先盲听；再显示英文并复听；之后显示中文（若已配译文），进入下一句。当前实现不是“自动播放三次”，也没有录音跟读评分。首次使用建议选一个短区间，确认节奏合适。

**听写模式**：输入听到的英文，按回车提交。红色删除线标出写错的内容，橙色底线标出漏掉的词。校对后再次按回车进入下一句，也可以选择提示一个词或跳过。结果是与页面原文的文字比对；若原文有误，校对也会受影响。

## 学习记录与导出

页面尝试将已练、星标、揭开状态和设置保存到当前浏览器的 localStorage。它不提供账号同步；换设备、换浏览器、无痕模式、清理浏览器数据或移动文件后，记录可能无法沿用。文件内的音频不依赖这些记录。

| 导出按钮 | 实际输出与注意事项 |
|---|---|
| 区间合并音频 | 当前区间的合并 MP3；生成后先在目标播放器试播 |
| 全部音频 + Anki 导入包 | ZIP，包含逐句 MP3、CSV 和导入说明；不是可双击导入的 `.apkg`。按说明复制音频、映射字段，并检查发音 |
| 中英对照文本 | 文本文件；没有提供译文的句子，中文为空 |

本轮已验证页面单句播放、原文揭开、星标保存和听写校对。手机、跨浏览器导出及 Anki 实际导入没有在本轮验收，暂不作兼容保证。

## 自己制作：让 AI 使用这个 Skill

复制下面这段话给 **WorkBuddy、豆包工作或 Codex**，再提供你的音频。有配套原文，也一起给；初次接触智能体，可以先用 WorkBuddy。

> 请帮我安装这个四六级逐句精听 Skill：https://github.com/yb-beep/listening-sentence-index 。按仓库说明准备好环境；如果我还没提供音频，请提醒我提供。收到音频后，生成带英文原文和中文译文的单文件精听网页，抽查句首句尾，自动打开成品，并在桌面创建「四六级逐句精听」快捷方式，让我以后双击就能练。最后简单告诉我：怎么开始练，以及下次换音频时该发什么话。

下载、安装与制作由智能体读取仓库说明后处理。它需要有文件和脚本执行能力；首次还需要准备依赖与识别模型。

### 给智能体或进阶使用者的命令参考

下面是制作流程的参考，初次使用只需发送上面的提示词。

在 Skill 解压目录中，使用已安装依赖的 Python：

```bash
python scripts/prepare.py --install
python scripts/run_all.py --work ./out --audio ./listen.mp3 \
  --ref ./reference.txt --title "我的听力材料"
```

没有原文时，去掉 `--ref`。自动转写仍需检查，特别是数字、专有名词和长句。

脚本不会自动调用大模型生成中文。需要 AI 逐句翻译并写入 `translations.json`；分批翻译可用 `merge_translations.py` 合并。加入译文后，再运行：

```bash
python scripts/build_index.py --work ./out
python scripts/make_single.py --work ./out --restart
```

成品位于 `out/我的听力材料（单文件版）.html`。

中断后：`transcribe.py` 可以按音频块续传；完整流水线用 `run_all.py --work ./out --resume` 跳过已记录完成的步骤。更换输入或修正上游时间轴后，需重新生成受影响的下游产物。

`run_all.py` 当前不接受 `--limit`、`--jobs`、`--batch-size`；这些参数要直接传给支持它们的分步脚本。

## 制作完成后的检查

先用随附的 `check_page.js` 检查页面，再抽听 5–10 对相邻句子，特别留意句尾、句首、题目和长句。自动识别、原文对齐与静音边界优化都需要核验，不能视为人工校对完成。

模型与依赖已就绪后，本地语音识别可以不依赖在线转写服务。AI 翻译是否联网、材料是否发送给外部服务，取决于所用 AI 工具和设置。

## 常见问题

**没有声音**：先确认打开的是单文件版，改用电脑系统浏览器。聊天软件的附件预览不等于浏览器运行页面。首次要点击播放，浏览器通常不允许无操作自动出声。

**中文为空**：制作时没有加入译文，或编号与句子不对应。先检查 `translations.json`，再生成页面。

**一句里出现下一句开头，或词只剩半截**：返回制作阶段，检查时间轴并参照 `references/boundary-tuning.md` 调整，重生成相关片段与单文件页。页面的连播起止按钮不能修音频边界。

**手机打不开**：本地 HTML 的打开与音频播放受系统、文件管理器和浏览器限制。优先在电脑练习；手机端在实际设备验证后再提供具体步骤。

**可以发给别人吗**：技术上可以发送单文件成品。它包含音频和原文，公开发布演示时请使用有相应授权的素材。
