# 代码检查与修复说明

已检查 13 个执行脚本，修复集中在 11 个文件，涉及音频解码、句子生成、补漏、断点续跑、网页练习与导出。原始版本已经备份。当前版本为 v0.1.1。

## 发现的问题与结果

| 问题 | 原来的触发条件与影响 | 本次修复 |
|---|---|---|
| PCM 音频被重复放大 | WAV 解码已经是 int16，却又乘 32767，可能让波形饱和失真；交错声道也可能被错误处理 | 使用 PyAV 转为统一的 planar int16；规范单/双声道，多声道下混为双声道 |
| 能量窗的时间步长漂移 | 22050Hz 等采样率的整数窗并非正好 10ms，按固定时间换算会在长音频上逐渐漂移 | 使用实际窗长除以采样率作为时间步长 |
| 补漏处理只接受双声道 | 单声道材料写补漏 WAV 时固定指定 stereo，可能编码失败 | 按实际布局写出；短音频的能量计算也增加边界处理 |
| 默认模型别名不一致 | 主转写把 turbo 转成实际仓库名，补漏和校验却直接使用别名，可能再次下载失败 | 三个识别入口使用相同别名映射 |
| 短尾音频被跳过 | 不足半秒的材料或最后一小段，分块循环可能直接退出 | 短材料仍生成一块；最后不足半秒的尾部并入最终块 |
| 句子顺序与短回答错误 | 无词时间戳的段落插在未结束句子前；Yes./No. 可能与下一句合并 | 先提交未结束句子；单词回答单独成句，并避开常见称谓缩写与题号 |
| 译文检查参数不能用 | `merge_translations.py --check` 在参数解析时被拒绝 | 注册参数，检查模式不写入合并译文 |
| 相对输入路径失效 | 配置保存相对路径，换工作目录运行后指向错误文件 | 保存绝对输入路径，沿用已有语言设置 |
| 断点和重做错误跳过 | 重做失败后保留旧完成记录；旧成品存在时，新转写尚未完成也可能继续下游；断点尾部可能重复 | 提前清理完成记录；检查真实产物；提交进度字节数并截去未提交尾部；音频/原文/模型变化触发重做并备份旧译文 |
| 使用旧片段或旧网页 | 时间轴、源码、译文或板块名更改后，旧结果可能仍被沿用 | 核对片段边界和输入更新时间；网页更新依赖包含音频、板块说明与模板 |
| 中文材料共用记录 | 中文标题被全部去掉，句数相同的多份材料可能使用相同 localStorage 键 | 用标题、文本和时间轴生成稳定摘要，各份材料分别记忆 |
| 星标筛选后仍连播全部句子 | 筛选只隐藏行，播放状态机仍按原序号连续推进 | 连播与前后句按可见句子推进；取消星标后立即更新筛选 |
| 分组、循环与三阶段状态不一致 | 最后一组可能不重复；无限循环不记录已练；三阶段开始前仍露出上次原文 | 最后一组按次数重复；循环结束提交已练记录；每句三阶段从遮住原文开始，并分别保存显示模式与练习模式 |
| 听写多写词仍可得 100% | 只用原文词数作分母，额外输入没有影响分数；重复单词提示也会漏掉 | 额外词影响得分；按文字差异提示重复单词 |
| Anki 与文件导出混淆 | 音频字段使用未闭合的 HTML audio；不同材料都导出 clip_001，容易重名；文件名固定带六级考试日期 | 使用 Anki 原生声音字段、明确列名与正背面映射；音频名包含材料摘要；导出文件使用当前标题 |
| 索引 HTML 直接插入原文 | 文字含 `<`、`&` 或类似标签的内容时，可能变成页面结构甚至执行脚本 | 标题、原文和板块名进行 HTML 转义；整段音频保留实际扩展名 |
| 板块按钮位置不合法 | 在 tbody 中插入 div，浏览器会移动节点 | 按钮放到 table 后，保持正确的板块结构 |

## 实际验证

- **15 项 Python 回归测试通过**：单/双声道 PCM、MP3 编解码、短音频及尾部覆盖、译文检查、句子顺序、补漏 WAV、记录隔离、失败后的续跑、缺失成品、输入改变与旧译文备份、断点未提交尾部、HTML 转义、短回答和跨目录路径。
- **12 项浏览器检查通过**：真实 MP3 播放、星标筛选连播、最后一组重复、三阶段盲听、循环记录、听写多余词、重复词提示、模式保存、ZIP 导出、材料名称、板块按钮结构和无脚本异常。
- **实际切分与页面生成通过**：将 6 句自编英语合成语音作为单声道 WAV 输入，运行 split、build_index、make_single，生成 6 个有效 MP3 和可播放的单文件 HTML。
- **导出验证通过**：ZIP CRC 正确，6 行 CSV 的 Anki 声音字段和媒体文件对应；所有 MP3 可解码；合并音频包含整组选定片段。

回归测试中的识别模型使用可控替身，验证断点和流水线管理。真实 Whisper 的识别质量、考试音频对齐精度、各智能体完整安装流程及 Anki 客户端实际导入仍需在对应材料和环境验收；本次没有把这些标作已通过。

## 已有成品如何更新

已生成的 HTML 保存着当时的网页代码，不会跟随 Skill 自动升级。重新生成才能使用本次修复；新版采用独立的学习记录标识，重生成时可能不会沿用旧网页的星标。原有网页可保留用于查看旧记录。

## 文案新增场景

字幕一开都认识，关掉又听不清；前半句刚反应过来，后半句已经过去；不知道到底漏了哪个词；昨天卡住的五句，今天复习又要重新找。文章和图卡把这些写成练习中的示例场景，方便学生代入。

## 保存与发布

本机 Skill 的相应脚本和制作指令已更新；桌面分享 ZIP 与 GitHub v0.1.1 同步更新。修改前的源码和桌面 ZIP 已在作者本机另行备份，公开安装包包含修复后的版本。代码改动见 `代码修复补丁.patch`。
