# 四六级听力，终于能一句一句练了

摘要：最近练听力，我顺手做了一个逐句精听工具。把自己的音频做成一个网页，点一句听一句，循环、减速、听写、难句复习都在同一页。文末附了可以直接复制的提示词和上手说明。

![四六级逐句精听封面](assets/01-四六级听力-一句一句练.png)

最近练四六级听力的时候，我发现，很多时间其实花在了“找那一句”上。

明明只是有一句没听清，却要拖着进度条来回找。拖早了，得再听前面一截；拖晚了，又错过句子开头。原文一打开，单词都认识，可关掉再听，还是反应不过来。

还有几种场景，练过精听的人大概都不陌生：

- **前半句刚听懂，后半句已经过去了。** 想重新听，又要回放整段。
- **知道自己没听懂，却不知道漏了哪个词。** 连读、小词、词尾，听着总是模模糊糊。
- **今天卡住的几句，明天又得重新找。** 上次的难点没留住，复习还是从头开始。

所以，我顺手把这些重复的操作整理成了一个「逐句精听」Skill，分享给同样在练听力的朋友。

你可以把 Skill 理解成一份给智能体的做事说明：把音频交给它，它按流程制作，你拿到一份可以直接打开练习的网页。

**四级、六级都可以用。想听哪句就点哪句，没听懂就留在这一句。**

## 01 把自己的音频，变成一页精听材料

![音频变成逐句精听网页](assets/02-一份音频-一页精听.png)

你准备听力音频，有配套原文也一起提供。智能体按照这套 Skill 处理转写、切分、译文和页面制作，最后生成一个精听网页。

播放入口、英文原文、中文对照和练习功能都在同一页，不用在播放器与文档之间反复切换。

音频也装进了单文件版网页。制作完成后，在电脑浏览器打开就能练，**之后离线也能用**。

## 02 先听，听完再揭开原文

![先盲听，再揭开原文](assets/03-先听-再看原文.png)

页面默认遮住原文。先听一遍，听不清就再播；需要确认时，只揭开当前这一句。

对照完，再遮住听一次。这样更容易发现：这句话是看到文字才明白，还是耳朵已经能听出来了。

## 03 卡住的那一句，循环到听清

![单句循环和减速](assets/04-循环减速-单句练透.png)

选「循环本句」，这一句就能反复播放，不用每次都去拖进度条。

觉得太快，可以先调到 0.75 倍，听清后再回到原速。如果单句听懂了，连起来又跟不上，还可以选几句连播，两三句一组练。

把时间花在正在卡住的地方，练起来会更顺手。

## 04 听不清哪里，就写下来对照

![听写与逐词校对](assets/05-听写校对-看见漏词.png)

切到听写，把听到的英文打出来，提交后和原文逐词比较。写错的、漏掉的，会在页面里标出来。

比如把 **room is** 听成 **rooms are**，对照后就知道该回去听哪几个词。卡住时，也可以先提示一个词。

听写给你一个具体的复听目标：回到音频里，确认自己刚才漏掉了什么。

## 05 难句标个星，下次接着练

![星标难句与集中复习](assets/06-星标难句-下次接着练.png)

这次没听懂，先给它标颗星。下一轮选择「只看星标」，集中复习这些句子。

听懂一条，就取消一颗星。今天卡住的地方，明天还能接着练。

## 06 不会安装也没关系，把这段话发给智能体

![把提示词发给 WorkBuddy、豆包工作或 Codex](assets/07-交给智能体-开始练习.png)

可以用 **WorkBuddy、豆包工作或 Codex**。第一次接触智能体，建议先从电脑端 WorkBuddy 开始。

这里的“智能体”，就是能按你的要求处理电脑文件、执行任务的 AI 助手。你不用先学命令，直接把下面这段话发给它，再提供音频即可。

**如果 GitHub 打不开，可以私信我，我直接把 Skill 安装包发给你。** 收到后，把压缩包拖给 WorkBuddy，继续使用下面同一段提示词。

> 请帮我安装这个四六级逐句精听 Skill：https://github.com/yb-beep/listening-sentence-index 。优先使用我提供的安装包，否则从仓库下载；按包内说明准备好环境；如果我还没提供音频，请提醒我提供。收到音频后，生成带英文原文和中文译文的单文件精听网页，抽查句首句尾，自动打开成品，并在桌面创建「四六级逐句精听」快捷方式，让我以后双击就能练。最后简单告诉我：怎么开始练，以及下次换音频时该发什么话。

首次制作要准备依赖和语音识别模型，可能需要等一会儿。智能体需要具备文件处理和脚本执行能力；有配套英文原文时，一起提供更方便核对。

制作完成后，让它打开成品，并按提示词创建桌面上的「四六级逐句精听」快捷方式。以后双击图标，就能继续练这份材料。

## 拿到网页后，照着这五步开始练

1. **打开材料。** 双击桌面的「四六级逐句精听」图标；也可以用电脑浏览器打开生成的单文件版网页。
2. **先盲听一句。** 保持原文隐藏，点这一行的 ▶。
3. **没听清就循环。** 把「每句」改成「循环本句」；需要时调慢语速，听清后再回原速。
4. **对照后再听。** 点「显示本句」，看完重新遮住，再听一次；想找漏词，就切到听写。
5. **把难句留下来。** 点 ☆ 标星，下次选择「只看星标」集中复习。

第一次先练几句就好。功能不用一次全开，先把“盲听 → 对照 → 再听”这一个动作练顺。

### 下次换音频，直接这样说

把新音频发给同一个智能体，再复制这一句：

> 请用已经安装的逐句精听 Skill，把这份新音频做成带英文原文和中文译文的单文件精听网页，抽查句首句尾，打开成品，并更新桌面的「四六级逐句精听」快捷方式，让它指向新材料。请保留之前的练习文件。

### 遇到小问题，先看这里

- **没有声音？** 用电脑浏览器打开网页，再点击播放；聊天软件里的附件预览可能无法正常播放。
- **中文没有出来？** 把网页交回智能体，说：“请补齐中文译文，重新生成并打开成品。”
- **句首句尾被切掉？** 告诉智能体是哪一句，让它检查切分边界并重新生成。
- **换设备后找不到星标？** 记录保存在当前浏览器里。尽量固定电脑、浏览器和文件位置练习。

自动转写可能出错，听写校对也以页面原文为准。遇到可疑的单词，结合音频和配套原文确认一下。
