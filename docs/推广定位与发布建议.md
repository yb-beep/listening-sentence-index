# 四六级逐句精听：这套宣传在表达什么

核心定位：**把自己的四六级音频，变成一句一句可以练的材料。**

面向想精听、但反复找音频位置很麻烦的备考学生。先让读者看到一个具体场景：大意懂了，那一句没听清；再用真实页面证明“点句就播、循环、听写、星标”怎么解决练习中的动作。

## 这套内容的使用顺序

1. 封面让人看懂：四六级听力，可以一句一句练。
2. 第二张说明成品：输入自己的音频，得到精听网页。
3. 第三到第六张展示练习：先听、循环、听写、复习。
4. 第七张给出入口：一段提示词交给 WorkBuddy、豆包工作或 Codex，提供音频，成品有桌面快捷方式。

公众号与小红书共用同一套标题、图卡和正文。需要缩短正文时，用《发布使用说明》中的同稿摘录。只保留 WorkBuddy、豆包工作、Codex 三个入口，以 WorkBuddy 为初次使用者的优先入口。

## 值得观察的反馈

先观察读者是否能看懂“自己的音频→精听网页”，以及复制提示词后是否能完成第一份短材料。收到问题时记录卡在下载、依赖、原文、译文、边界、桌面入口还是开始练习，优先改实际卡点。

一份用户授权公开的前后对比，能帮助展示效果：原音频中的一句话、对应的精听页，以及循环和听写的实际操作。公开素材应使用自编或具有相应授权的内容。

## 宣传口径

强调顺手的练习动作、自己的材料、单文件成品和桌面入口。不使用固定制作耗时、自动提分、百分比准确率或没有依据的全平台保证；没有用户实测就不编使用人数和评价。页面支持与客户端接入情况以实际版本与检查结果为准。

图卡中的示例来自真实页面模板，自编英语和合成语音。完整识别与切分流水线沿用已有 Skill；本轮主要完成文案、图片、公开包整理和页面交互检查。

## 新增的练习场景

开字幕认识词、关字幕听不清；前半句懂了后半句已经过去；不知道具体漏哪个词；隔天复习难点没留住。这些写成让读者代入的示例场景，放在开头和对应功能图里。没有编造成真实用户采访、成绩变化或使用评价。
