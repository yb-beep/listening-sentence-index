# 这次发布用这一套

## 完整稿

`完整版图文-含上手说明.md` 与 `宣传文案-公众号小红书通用.md` 内容相同：个人练习缘起、功能介绍、安装提示词、五步练习、换音频提示词和常见问题，已经合在一篇里。

`完整版图文-含上手说明.html` 是完整稿的单页阅读版。`宣传图文预览.html` 的首个页面也是同一完整稿，并可查看配图及详细使用说明。

## 发布顺序

公众号请先打开 `公众号发布版.html`。它提供独立的标题、摘要、正文复制按钮；复制的正文带内联排版和 01–07 配图位置提示。图片须在公众号编辑器里上传，复制粘贴本地 HTML 不能保证把图片一并带过去。

`公众号发布素材.zip` 包含发布版、标题与摘要、7 张配图和横版封面，便于单独取用。

公众号：用 `assets/公众号封面-横版.png` 作封面，按完整稿中的位置插入 01–07 图卡。上手说明已经包含在文末，直接发布这一篇即可。

小红书：按 01–07 上传同一组图卡；文字配合完整稿内容按平台实际限制精简，保留私信领取安装包的入口。

转发：标题和配文在 `转发标题与配文.md`；也可以从 `转发配文-直接复制.txt` 直接复制。

## 给读者的入口

文章中的同一段提示词，支持从 GitHub 获取 Skill，也支持优先使用读者已收到的安装包。GitHub 打不开时，读者私信作者领取包，把压缩包拖给 WorkBuddy，再提供提示词与音频。

工具仓库：https://github.com/yb-beep/listening-sentence-index

Skill ZIP：https://github.com/yb-beep/listening-sentence-index/releases/latest/download/listening-sentence-index-skill.zip

本地可直接发给读者的文件：`listening-sentence-index-skill.zip`。

`使用说明书.md` 保留完整功能表、导出说明和制作参考，作为独立资料查阅。完整稿里的上手说明已覆盖初次使用所需步骤。
